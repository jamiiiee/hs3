# Route Times - Higher or Lower

A mobile-first guessing game where you compare UK train and ferry journey times.

## How to Play

1. You're shown two routes with their origin and destination
2. The top route shows its journey time, the bottom route is hidden
3. Guess if the second route takes **Higher** or **Lower** time
4. Get it right to keep your streak going!
5. Get it wrong and the game ends - try to beat your high score

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to play.

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript
